# cl-asciiquarium

An original ASCII-art aquarium screensaver for the terminal: swimming fish, a
shark, rising bubbles, swaying seaweed, and periodic special guests, rendered
live via [cl-tty-kit](https://github.com/nerima-lisp/cl-tty-kit). Every sprite
is original art authored for this repository -- none of it is copied from the
classic Perl `asciiquarium`.

See [Getting started](getting-started.md) to run it, [Keybindings and
CLI](guide/usage.md) for how to drive it, and [Architecture](reference/architecture.md)
for how the simulation is put together and what this v1 deliberately included
versus cut.
